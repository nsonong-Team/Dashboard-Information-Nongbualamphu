Mode: Operate (หน้าทำงาน) พร้อม hero เปิดตัว · Build path: code-led (ไม่มีการสร้างภาพในเซสชันนี้)

Constraints: ข้อมูลสดจาก GD Catalog เท่านั้น, GitHub Pages, ไทย, WCAG AA, reduced motion

## Direction contract

THESIS: หน้านี้คือ "ห้องควบคุมยามค่ำของบึงบัว" — ความพร้อมของข้อมูลจังหวัดอ่านเป็นสัญญาณไฟสามสี ปฏิเสธ dashboard สถิติทั่วไปที่เรียง KPI บนพื้นขาว

OWN-WORLD: พื้นน้ำเงินกรมท่าคืนเดือนมืด (ไม่ใช้ดำสนิท) เหลืองอำพัน = มีข้อมูลปีปัจจุบัน + ปุ่มหลัก, น้ำเงินไฟฟ้า = ผ่านเงื่อนไข/API, แดงบัว = ไม่ผ่าน/ต้องตาม · ภาพถ่ายจริงของจังหวัดยามพลบค่ำ · ตัวอักษรเหลี่ยมแบบป้ายสัญญาณ (Chakra Petch) คู่ Anuphan · วงสัญญาณซ้อนสองชั้นเป็นภาษาหลักของทุกการ์ด

STORY: เปิดมาเห็นภาพรวมทั้งจังหวัดและวงสัญญาณใหญ่ → การ์ดเรียงจากพร้อมน้อยสุด → กดการ์ดเห็นรายชุดข้อมูลพร้อมเหตุผล → ส่งออก CSV ไปติดตาม

FIRST VIEWPORT: แถบนำทางซ้ายแคบ (โลโก้ สสจ. บนป้ายพื้นอ่อน + 3 เมนู) · ฝั่งซ้ายของ hero หัวข้อสองบรรทัดใหญ่ "ข้อมูลจังหวัด / พร้อมแค่ไหน" (บรรทัดสองสีอำพัน) + ประโยคอธิบาย + ปุ่มหลัก "ดูประเด็นที่ต้องติดตาม" · ฝั่งขวาเป็นภาพจังหวัดยามค่ำเฟดเข้าพื้น ทับด้วยวงสัญญาณใหญ่ของทั้งจังหวัด (นอก=ปี 2569, ใน=ผ่านเงื่อนไข) · ขอบล่างคือแถบควบคุม (ค้นหา ตัวกรอง สลับประเด็น/หน่วยงาน)

FORM: signal-board ops console · seed: none (pinned) — "theme สีของเว็บ... สีน้ำเงิน+เหลือง+แดง ตัวเว็บยังคงสไตล์โทนมืด", "ทำเป็นการ์ด", ภาพอ้างอิง LUMEN Transit Ops
