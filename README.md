# คลังไฟล์ข้อมูลจังหวัดหนองบัวลำภู

Dashboard สำหรับค้นหาและดูไฟล์ข้อมูลทั้งหมดจาก [GD Catalog จังหวัดหนองบัวลำภู](https://nongbualamphu.gdcatalog.go.th/dataset/)
ดึงข้อมูลสดจาก API (CKAN) ทุกครั้งที่เปิดหน้า ไม่ต้องมีเซิร์ฟเวอร์หลังบ้าน

## ความสามารถ
### แท็บ “ไฟล์ทั้งหมด”
- สรุปจำนวนชุดข้อมูล ไฟล์ หน่วยงาน ช่วงปี และวันที่อัปเดตล่าสุด
- กราฟจำนวนไฟล์ตามปี (พ.ศ.) คลิกแท่งเพื่อเลือก/ยกเลิกปี (เลือกได้หลายปี)
- ตัวกรองทุกตัวเป็น dropdown ที่ **ค้นหาข้างในได้ เลือกได้หลายค่า** และแสดงจำนวนไฟล์ของแต่ละตัวเลือก
- ตัวเลือกปีมี 2 โหมด: **เลือกรายปี** (ติ๊กหลายปี) และ **ช่วงปี** (ตั้งแต่…ถึง…) พร้อมปุ่มลัด 3/5/10 ปีล่าสุด
- ดาวน์โหลดไฟล์ / เปิดหน้าเว็บต้นทาง / ดูตัวอย่างข้อมูลในหน้า (ไฟล์ที่มี DataStore)
- ส่งออกรายการไฟล์ที่กรองแล้วเป็น CSV (เปิดใน Excel ได้)
- รีเฟรชอัตโนมัติทุก 15 นาที / 1 ชั่วโมง, ธีมสว่าง/มืด

### แท็บ “ตรวจสอบตามเงื่อนไข”
ตรวจทุกชุดข้อมูลตามเงื่อนไข (ปรับค่าได้ในหน้าเว็บ):
1. ข้อมูลย้อนหลังครบ 5 ปี (ค่าเริ่มต้น 2565–2569)
2. มีข้อมูลปีปัจจุบัน (ค่าเริ่มต้น = ปี พ.ศ. ปัจจุบัน)
3. มีไฟล์ Machine readable อย่างน้อย 1 ไฟล์ (CSV, XLSX, XLS, JSON, XML, API, ODS, TSV, GeoJSON, KML, SHP — PDF/HTML/DOCX/รูปภาพ/RAR ไม่นับ)
4. ตารางสรุปรายหน่วยงาน (จำนวนที่ผ่านแต่ละข้อ + % ผ่านครบ) คลิกเพื่อดูรายชุดข้อมูล
5. ตารางรายชุดข้อมูล มีแถบปีสีเขียว/แดง บอกปีที่ขาด และเหตุผลที่ไม่ผ่าน, ส่งออกผลตรวจเป็น CSV

ไอคอนจาก [Google Material Symbols](https://fonts.google.com/icons)

## รันในเครื่อง
ต้องมี [Node.js](https://nodejs.org/) 18 ขึ้นไป

```bash
npm install
npm run dev
```
แล้วเปิด http://localhost:5173

## นำขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub (Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ branch `main`
   (ไม่ต้องอัป `node_modules/` และ `dist/` — `.gitignore` กันไว้แล้ว)
3. ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
4. ไปที่แท็บ **Actions** รอให้ workflow “Deploy to GitHub Pages” ขึ้นเครื่องหมาย ✓
5. เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

หลังจากนี้ทุกครั้งที่แก้โค้ดแล้ว push เข้า `main` เว็บจะอัปเดตเองภายใน 1–2 นาที

## โครงสร้างไฟล์
```
src/
  api.js                  เรียก API (JSONP), แปลงข้อมูล, หาปีของไฟล์, ส่งออก CSV
  App.jsx                 หน้าหลัก + state ตัวกรอง
  components/
    Filters.jsx           ช่องค้นหาและตัวกรอง
    MultiSelect.jsx       dropdown ค้นหาได้ + เลือกหลายค่า
    YearPicker.jsx        ตัวเลือกปี (รายปี / ช่วงปี)
    Compliance.jsx        แท็บตรวจสอบตามเงื่อนไข
    Icon.jsx              ไอคอน Material Symbols
    YearChart.jsx         กราฟจำนวนไฟล์ตามปี
    BarList.jsx           กราฟแท่งแนวนอน (หน่วยงาน / รูปแบบไฟล์)
    FileTable.jsx         ตารางรายการไฟล์
    PreviewDialog.jsx     หน้าต่างดูตัวอย่างข้อมูล
  styles.css
.github/workflows/deploy.yml   build + deploy อัตโนมัติ
```

## หมายเหตุ
- API ของพอร์ทัลไม่เปิด CORS จึงเรียกแบบ JSONP (`?callback=`) ซึ่ง CKAN รองรับ
- ปีของไฟล์ใช้ค่าที่หน่วยงานกรอกไว้ ถ้าไม่มีจะอ่านจากชื่อไฟล์ (เช่น “ปี 2565-2568”) บางไฟล์จึงอาจไม่มีปี
- หากต้องการเปลี่ยนไปใช้พอร์ทัลจังหวัดอื่น แก้ค่า `BASE` ใน `src/api.js`
